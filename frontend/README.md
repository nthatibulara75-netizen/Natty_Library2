NATTY LIBRARY — REACT FRONTEND
===============================

1. Make sure XAMPP MySQL is running.
2. Make sure the Express backend is running in a separate Command Prompt.
3. Open a SECOND Command Prompt in this frontend folder.
4. Run: npm install
5. Run: npm run dev
6. Open http://localhost:5173 in your browser.

Keep this Command Prompt window open while using the local website.
The frontend sends requests to http://localhost:5000, where the backend API runs.
